# Assetto Corsa RaceCore — Master TODO

Project folder: `AC_RaceCore`
Project name: Assetto Corsa RaceCore
Short name: RaceCore

## Architecture decisions

* [x] Run RaceCore as a separate local backend/service with browser interfaces and PostgreSQL
* [x] Use a lightweight CSP Lua app as the in-game companion, not the source of authoritative race state
* [x] Keep the source repository outside `assettocorsa/apps/lua`; deploy only the CSP client there
* [x] Package and install the RaceCore host independently as a user-level Windows app
