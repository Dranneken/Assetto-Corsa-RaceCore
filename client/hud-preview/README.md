# RaceCore HUD preview

Open `index.html` in a browser. It runs locally without a server or extra packages and uses the same texture files as the CSP client.

The toolbar can show or hide each HUD, switch between race and practice/qualifying lap labels, and adjust RPM, steering, throttle, and brake values. This is a visual layout preview with sample leaderboard data; AC telemetry and Lua behavior still need to be checked in game.
