# RaceCore HUD preview

Open `index.html` in a browser. It runs locally without a server or extra packages.

The gallery previews the driver HUDs, including the Gearbox/RPM panel based on the Rennsport Essentials layout. The Session + Leaderboard composite is now the in-game **RC Session/Leaderboard** HUD; this page still uses sample session and telemetry data. The live leaderboard draws one marker per track split: thin gray when unset, neutral gray when set without a comparison, yellow for a nonzero change under one second from the previous lap's same sector, red when at least one second slower, green for a personal best, and purple for the field best. The preview shows three sample markers because it has no live track data. Position movement is shown inline as `+N` or `-N`, with no added column. The Driver column combines car number and name, keeping the number fixed while only the name scrolls when it overflows. The leaderboard also includes each car's CMRT-style tyre compound short name before the sector bars, combines best and last lap time into one column, and cycles its adjacent-car interval column between Interval for six seconds and leader-relative Gap for two seconds. Time precision follows the P1/P2 gap: tenths at 100ms or wider, hundredths under 100ms, and thousandths under 10ms or when the comparison is unavailable. The sample session simulates lap-based Race from `00:00:00` or a timed Race countdown; completed laps advance during simulation. Practice and Qualifying show timed samples. Use Pause to hold the preview values. RPM, speed, gear, session, throttle, and brake controls also update the samples. All values are sample data; actual CSP rendering and telemetry should be checked in game.
